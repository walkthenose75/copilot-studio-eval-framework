A vendor-neutral, production-oriented blueprint for turning Copilot Studio agent evaluation into a repeatable, auditable enterprise quality gate — standardized test sets, automated grading, CI/CD release gates, a Dataverse results repository, and Power BI governance reporting, with a runnable open-source starter pack.

What's inside

Standardized test sets

Multi-method single-response test cases with a documented import format and retention rules.

Automated grading & gate

Per-case pass/fail plus aggregate scores, wired into an objective quality gate with a clear pass/fail contract.

CI/CD release gates

GitHub Actions / Azure DevOps patterns: deploy → evaluate → promote on pass, plus scheduled drift detection.

Dataverse results repository

A schema for persisting every run so quality is queryable, auditable, and trend-able over time.

Power BI governance reporting

Turn stored results into estate-wide quality and drift dashboards for owners and reviewers.

Runnable starter pack

A Python eval runner, test seeds, YAML workflows and a pytest suite — clone it, point it at an agent, and gate the same day.

Good to know

Standard-harness, response-level, and future-proof. The framework targets the Copilot Studio standard harness, where agent evaluation is automatable today via the Power Platform REST API and connector actions. The approach is response-level rather than harness-specific, so the same gate logic and results schema carry over as the newer agent experience reaches method and API parity.

Reference implementation, not an official product. This is a personal reference framework — not an official Microsoft product and not a tenant-verified deployment. The runner was exercised end to end against a mock of the documented API surface; response field names and status tokens are written defensively but not yet verified against a live tenant. A one-time shakeout closes that gap. See the repo's PROVENANCE and SHAKEDOWN notes for exactly what has and has not been validated.
